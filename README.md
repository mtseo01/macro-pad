# ⌨️ 물리 매크로 키보드 핸들러 (Windows 11)

이 프로그램은 물리 매크로 키보드의 **F13 ~ F24** 키를 감지하여, 미리 설정된 문자열을 클립보드에 복사한 후 자동으로 붙여넣어 주는 도구입니다.

## ✨ 주요 특징
- **Zero-Dependency**: 외부 라이브러리 설치가 전혀 필요 없습니다. (Python 표준 라이브러리만 사용)
- **다국어 지원**: 한글, 영어, 일본어 등 모든 유니코드 문자를 완벽하게 처리합니다.
- **장문 지원**: 1,000자 이상의 긴 텍스트와 줄바꿈이 포함된 텍스트도 "팟!" 하고 입력됩니다.
- **회사 보안 최적화**: `pip install`을 할 수 없는 환경에서도 `macro.py` 파일만 있으면 실행 가능합니다.

## 🚀 사용 방법
1. `macro.py`와 `config.json` 파일을 같은 폴더에 둡니다.
2. `config.json` 파일을 열어 원하는 매크로를 설정합니다. (아래 설정 가이드 참고)
3. 터미널(CMD 또는 PowerShell)을 열고 아래 명령어를 입력합니다.
   ```bash
   python macro.py
   ```
4. 프로그램이 "매크로 가동 중..."이라는 메시지를 띄우면, 입력창에서 F13~F24 키를 눌러 사용하세요.

## 📝 설정 가이드 (`config.json`)
JSON 형식에서는 특수 문자를 입력할 때 주의가 필요합니다.

- **줄바꿈 (Enter)**: `\n`을 입력합니다. (예: `첫 번째 줄\n두 번째 줄`)
- **큰따옴표 (")**: `\"`를 입력합니다. (예: `그가 말했다. \"안녕?\"`)
- **역슬래시 (\)**: `\\`를 입력합니다.
- **긴 텍스트**: JSON은 한 줄에 아주 긴 텍스트를 넣어도 문제없이 인식합니다. 편집기(VS Code, 메모장 등)의 '자동 줄바꿈' 기능을 켜고 작업하시면 편합니다.

## ⚠️ 주의 사항
- 프로그램이 실행 중인 동안에만 매크로가 작동합니다.
- F13~F24 키를 이미 다른 프로그램(예: 특정 업무용 툴)에서 핫키로 점유하고 있다면 작동하지 않을 수 있습니다.
- 종료하려면 터미널 창에서 `Ctrl + C`를 누르거나 창을 닫으세요.
